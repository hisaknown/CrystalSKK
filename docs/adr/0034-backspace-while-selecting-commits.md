# ADR-0034: ▼ での Backspace は確定してから一文字消す

- ステータス: Accepted
- 日付: 2026-09-24
- 関連: ADR-0018, ADR-0033

## 背景

▼ で Backspace を押すと、取り消し (C-g) と同じく ▽ に戻っていた。前の候補
へ戻る `x` とほとんど変わらない。

打ち直したいのはたいてい末尾の一文字である。候補は正しく、送り仮名や
活用語尾を打ち間違えている。

## 決定

ddskk と CorvusSKK の既定に合わせる。

1. **▼ で Backspace を押すと、確定してから一文字消す。** 学習はする。
   選んだ候補は正しいからである。
   - ddskk: `skk-delete-implies-kakutei` の既定は `t`。「▼モードで BS を
     押すと、前の一文字を削除し確定する」
   - CorvusSKK: 「後退に確定を含める」(`backincenter`) の既定は有効
2. **候補の一覧が出ているあいだは、Backspace も前の一覧へ戻る。** ddskk も
   CorvusSKK もこうする。一覧の中で確定すると、どれを選んだのか分かり
   にくい。
3. **▽ で送り仮名を打ちかけているときは、一文字と一緒に区切りも消す。**
   `▽おく*r` は `▽おく` になる。区切りだけ残っても、続けて打つかもう
   一度消すしかない。ddskk は ▽ での Backspace のたびに
   `skk-delete-okuri-mark` で区切りを消し、CorvusSKK も送り仮名の最後の
   一文字を消すと区切りを消す。

設定には出さない。前の候補へ戻る操作は `x` に残っている。

## 帰結

- 確定した後はただの文字になるので、送り仮名の区切りは文書に残らない。
  区切りは未確定のあいだの目印でしかない。
- `x` で ▽ に戻ったときは、これまでどおり区切りを落として `▽おくり` に
  なる (ADR-0018)。ddskk も区切りを出さない。
