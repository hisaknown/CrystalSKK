# ADR-0040: 設定ファイルが変わったら、辞書サーバが全ウィンドウへ知らせる

- ステータス: Accepted
- 日付: 2026-09-26
- 関連: ADR-0020, ADR-0016, ADR-0038

## 背景

設定ファイルの持ち主は辞書サーバで、TIP はサーバから全文を受け取った
**写し**を持つ (ADR-0020)。TIP はアプリの数だけいて、写しもその数だけある。

写しを取り直すのは、有効化されたとき、打鍵の受け口に焦点が入ったとき
(`OnSetFocus`)、トレイの「設定を読み直す」を押したとき (押したアプリだけ)
だった。ADR-0020 は「書き換えた設定は、入力先を切り替えたときに効く」と
約束していたが、守れていなかった。

- 別のアプリで設定を書き換えて Firefox に戻っても、`OnSetFocus` が来ず、
  古い写しのまま動いた。利用者には、書き換えが効かないようにしか見えない。
- トレイで読み直しても、ほかのアプリの TIP は古いまま。

TIP には、写しが古くなったことを知る手段が無かった。

## 選択肢

### A. 共有メモリに設定の世代番号を置く

サーバがファイルを見張って番号を進め、TIP は打鍵のたびに番号を読む。

- 利点: 次の打鍵から効く。打鍵ごとの手間はメモリの読み出し一回。
- 欠点: 変化を伝えるためだけに、新しい通り道と、隔離された入れ物からも
  読める権限の設定が増える。

### B. サーバの返事に設定の版を添える

TIP は変換や補完でいつもサーバと話している。その返事に、ファイルの更新
時刻と大きさから作った版を添え、TIP は自分の写しと見比べる。

- 利点: 新しいものがほとんど増えない。
- 欠点: 気づけるのは TIP がサーバと話したときだけ。直接入力でかなを打つ
  あいだは話さないので、キーの割り当てを変えても、次に辞書を引くまで
  古いまま。

### C. サーバが全ウィンドウへ一斉に知らせる

サーバがファイルを見張り、変わったら登録した独自のメッセージを
`PostMessage(HWND_BROADCAST, …)` で送る。TIP は受けたら写しを取り直す。

- 利点: 保存した直後に、どのアプリでも効く。Windows 自身が設定の変化を
  `WM_SETTINGCHANGE` で一斉に知らせるのと同じ形で、TIP はそれを受ける
  見えない窓をすでに持っている (タスクバーの明るさを聞く `theme::Watcher`)。
- 欠点: サーバにファイルを見張るスレッドが増える。管理者として動くアプリの
  窓には、そのままでは届かない (UIPI)。

## 決定

**C を採る。** 持ち主が変化を知らせ、写しを持つ側が取り直す。約束は
「保存すれば、どのアプリでもすぐ効く」になる。

### サーバ

- 設定ファイルの置き場所を `ReadDirectoryChangesW` で見張る。ファイルでは
  なく場所を見るので、エディタが別名で書いて置き換える保存の仕方でも
  気づける。
- 設定ファイルか、同じ場所にあるローマ字テーブルが変わったら、少し待って
  (エディタは一度の保存で何度も書く) から一度だけ知らせる。
- **見張りは知らせるだけで、読まない。** 読むのは、これまでどおり TIP に
  尋ねられたとき。サーバ自身の辞書やランカーもそこで設定に合わせている
  ので、読む場所を一つに保てる。
- 書き足し (ADR-0020) もファイルを変えるので、もう一度知らせることになる。
  二度目の読み込みでは書き足すものが無いので、そこで止まる。
- `PostMessage` は相手を待たない。固まっているアプリがあっても、サーバは
  止まらない。

### TIP

- 見えない窓 (`theme::Watcher` と同じ一枚) で知らせを受け、写しを取り
  直す。窓の手続きはアプリの UI スレッドで動くので、打鍵の処理と重ならない。
- 管理者として動くアプリでも受け取れるよう、その窓で
  `ChangeWindowMessageFilterEx` を呼び、このメッセージだけを通す。
- `OnSetFocus` での取り直しは、知らせを取りこぼしたときの備えとして残す。

### トレイの項目は「設定を検査する」にする

読み直すきっかけとしては要らなくなるが、二つの役目が残る。設定が読めて
いるか (読めないならその理由) を利用者が確かめることと、キーとローマ字の
ぶつかり (ADR-0038) を知らせることである。そこで名前を「設定を検査する」に
変え、押すと、サーバに一斉の知らせを頼んだうえで、いまの設定の状態を窓に
出す。知らせを頼むので、見張りの取りこぼしへの備えも兼ねる。

## 帰結

- ADR-0020 の「入力先を切り替えたときに効く」は、「保存すればすぐ効く」に
  置き換わる。
- ローマ字テーブルを設定ファイルと別の場所に置いた場合は見張らない。
  そのときは「設定を検査する」で知らせる。
- 知らせは同じデスクトップの全ウィンドウに届く。登録したメッセージなので、
  知らない窓は無視する。
- 見直す条件: 見張りが取りこぼす保存の仕方が見つかったとき。
