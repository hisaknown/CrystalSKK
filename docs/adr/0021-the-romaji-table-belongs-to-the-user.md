# ADR-0021: ローマ字テーブルは利用者の持ち物として別のファイルに置き、書き換えない

- ステータス: Accepted
- 日付: 2026-09-23
- 関連: ADR-0020, PRD F-14, PRD §5.3

## 背景

ローマ字の規則表は `RomajiTable::default_skk()` としてエンジンに埋め込まれて
いた。さらに変換器の中に、表に無い二つの規則が書かれていた。

- 促音: 同じ子音を重ねると `っ` (`kk` → `っ` + `k`)
- 撥音: `n` に子音が続くと `ん` (`nk` → `ん` + `k`)

どちらも利用者からは見えない既定値である。ADR-0020 は「ファイルに書かれて
いない値は効かない」と決めた。規則表も同じ扱いにする必要がある。

ただし規則表は `config.toml` とは性質が違う。

- **規則が一つ無いのは、たいてい利用者が消したからである** (`la` を `ぁ` に
  したくない、など)。`config.toml` のように「足りなければ書き足す」と、その
  意図を踏みにじる。
- 規則は 250 行を超える。`config.toml` に入れれば、ほかの設定が埋もれる。
- Google 日本語入力のローマ字テーブル (タブ区切りの三つ組) という、よく
  知られた形がすでにある。エンジンの `Rule` も同じ三つ組である。

## 選択肢

### A. `config.toml` の中に `[romaji]` 表として持つ

- 利点: ファイルが一つで済む。
- 欠点: 書き足しの規則がそのまま当たり、消した規則が戻ってくる。量が多い。

### B. 別のファイルに置き、版を上げたら差分を見せる

- 利点: 雛形が変わったことに気づける。
- 欠点: 規則表はほぼ利用者の持ち物である。差分を見せられても、取り込むか
  どうかの判断を毎回迫ることになる。

### C. 別のファイルに置き、作ったあとは一切触らない。戻したければ利用者が頼む

- 利点: 利用者のものに手を出さない。戻す道はトレイの品書きにある。
- 欠点: 雛形の改善は、利用者が戻さない限り届かない。

## 決定

**C を採る。**

- 規則表は `romaji.txt` (Google 日本語入力と同じタブ区切り三列、`#` 行は
  説明) に置く。場所は `config.toml` の `romaji.table` で決め、設定ファイルと
  同じ場所からの相対で書ける。**設定の入口は `config.toml` 一つのまま**である。
- ファイルが無いときだけ、同梱の雛形から作る。**あれば中身を書き換えない。**
  版を上げても触らない。
- 変換器の中の促音・撥音の規則は外し、雛形に**規則として書き出した**
  (`kk	っ	k`、`nk	ん	k` など)。表に無い規則は効かない。
- エンジンの規則表は設定と一緒に受け取る (`Options::romaji`)。既定の表は
  持たない。
- 読めない行があれば、一つ目の誤りの行番号と理由を言って、表全体を使わない。
  一部だけ読んで動くと、どの規則が効いていないのか分からない。

### 規則と SKK のキーがぶつかったとき

`l` (英数へ)、`q` (カタカナへ)、`/` (abbrev)、空白 (変換)、`.` (補完候補を
受け取る) は SKK のキーでもある。**打ちかけのローマ字があり、そこへ続けると
規則になる (またはその途中になる) なら、規則が勝つ。** 雛形の `z/` (・)、
`zl` (→)、`z ` (全角空白) はこうでないと打てない。ddskk も同じ順で見る。
打ちかけが無ければキーはキーとして働く。

この順のため、`nl` `nq` `ll` `qq` のような規則を書くと、`n` や同じ字の
あとで英数やカタカナへ切り替えられなくなる。雛形はこの四つを持たない。

### 雛形そのものを試験する

雛形は、利用者の多くがそのまま使う一つの設定である。`default.toml` と
`romaji.txt` を読んだ値でエンジンを動かす試験を置く
(`crates/crystalskk-settings/tests/shipped.rs`)。

- 表の**全規則**を、何もない状態から打って、そのかなが出ること
- 打ちかけの `n` のあとでも SKK のキーが働くこと
- 雛形の値で変換・一覧・動的補完が動くこと

`z/` が効かないまま出荷しかけたのは、この試験が無かったからである。

### 雛形に戻す道

トレイのアイコンを右クリックすると品書きが出る。

| 項目 | すること |
|---|---|
| 設定フォルダを開く | `%LOCALAPPDATA%\CrystalSKK` をエクスプローラーで開く |
| 設定を検査する | 設定が読めているかと、キーのぶつかりを窓に出す (ADR-0040 で「設定を読み直す」から改めた) |
| 設定ファイルを雛形で上書き… | 確かめてから `config.toml` を雛形にする |
| ローマ字テーブルを雛形で上書き… | 確かめてから `romaji.table` が指すファイルを雛形にする |

上書きの前には確かめの窓を出し、既定の答えは「やめる」にする。元の中身は
`<名前>.bak` (あれば `.bak2`, `.bak3` …) に退避し、前の退避は消さない。

ファイルに触るのはここでも辞書サーバである。隔離された入れ物の中のアプリ
からはファイルに触れず、エクスプローラーも立ち上げられないことがある。

## 帰結

- AZIK などの別配列は、ファイルを差し替えるか、`romaji.table` を別の
  ファイルに向けるだけで使える。
- 雛形の規則を直しても、既存の利用者には届かない。届けたいほどの直しなら、
  品書きから戻すよう案内する。
- PRD §5.3 の `romaji_rules()` (規則表の**差分**を返す拡張点) は、元になる
  表がどこかにあることを前提にしている。ファイルが表のすべてである以上、
  差分という形は取らない。スクリプトで規則表を扱うなら、表全体を返す形に
  する。
- 見直す条件: 設定 GUI (F-16) で規則表を編集するとき。そのときも書くのは
  このファイルである。
