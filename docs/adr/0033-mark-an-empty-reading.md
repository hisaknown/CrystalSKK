# ADR-0033: 読みが空になったら、変換開始の目印を出す

- ステータス: Accepted
- 日付: 2026-09-24
- 関連: ADR-0018, PRD Q-09

## 背景

ADR-0018 で `▽` `▼` は文書に何も出さないことにした。下線が状態を示して
おり、空白を置くと書いている文が一文字ぶん右へずれるからだった。

使ってみると困った。**SKK では、変換開始の目印だけを残して読みを
Backspace で消し、打ち直すことがよくある。** 印が場所を取らないと、読みを
全部消した時点で下線も消え、まだ ▽ にいるのかが画面から分からない。

加えて、エンジンも読みが空になった時点で直接入力へ戻していた。

## 決定

1. **読みを消し切っても `▽` のまま留める。** 空の `▽` でもう一度
   Backspace を押すと直接入力へ戻る。ddskk も CorvusSKK もこうする。
   空の `▽` で変換すると、何も確定せずに `▽` を抜ける。ddskk もこうする。
2. **`▽` は、読みがあるあいだは何も出さず、読みが空のときだけ空白を
   出す。** SKKFEP も CorvusSKK もこうしている。打っているあいだは文が
   ずれず、消し切ったときだけ下線の引かれた空白が目印になる。
3. **`▽` `▼` `*` をそれぞれ何で書くかは、`[markers]` の設定で選べる。**

| 項目 | 役目 | 雛形 | 伝統的な SKK |
|---|---|---|---|
| `composing` | `▽` をいつも何で書くか | `""` | `"▽"` |
| `composing_empty` | 読みが空のとき、その後ろに足すもの | `"\u00A0"` | `""` |
| `selecting` | `▼` | `""` | `"▼"` |
| `okuri` | `*` | `""` | `"*"` |

`composing_empty` の雛形は U+00A0 (NO-BREAK SPACE) とする。**普通の空白
(U+0020) は、区間の端にあると下線を引かないアプリがあった。** U+00A0 は
幅が普通の空白と同じで、線も引かれた。

`okuri` の雛形も空にした。境は下線の模様 (点線と破線) で示す。

設定を読めていないうちは、エンジンの記号のまま出す。

## 選ばなかったもの

- **印を常にごく細い空白 (U+200A) にする。** 一度はこうした。フォント次第
  で幅がまちまちで、打っているあいだも常に少しずれる。読みが空のときの
  目印としても、プロポーショナルフォントでは細すぎることが多い。
- **「`composing` が空のときだけ空白を出す」という暗黙の決まり。** 伝統的な
  記号に戻す人は設定が一つ減るが、効き方が見えにくい。項目を分けた。

## 帰結

- 定数 `MARKER_TEXT` `SEPARATOR_TEXT` を設定に置き換えた。ADR-0018 が
  「設定で選べるようにするときの置き場所」としていたものである。
- 伝統的な記号に戻す人は、`composing_empty` も `""` にしないと `▽` の
  後ろに空白が付く。雛形の説明に書いてある。
