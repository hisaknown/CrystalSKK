# ADR-0029: 欠けた辞書は知らせ、辞書登録には進ませない

- ステータス: Accepted
- 日付: 2026-09-23
- 関連: ADR-0016, ADR-0022

## 背景

辞書を取得できなかったとき、サーバは記録に残すだけで、利用者には何も
知らせていなかった。

手元に前の版が無い辞書 (たとえば初めての起動で通信できなかった L 辞書) は、
そもそも引けない。その辞書にしか無い語を変換すると、**候補が無いので辞書
登録が始まる**。利用者は「知っているはずの語が無いと言われた」と受け取り、
そのまま登録すれば辞書が汚れる。

## 決定

- 取得できず、手元にも無い辞書を**欠けている**とみなす。読めなかった手元の
  ファイルや、在りかが解けなかった辞書も同じ扱いにする。
- **欠けた辞書があるあいだに候補が一つも無ければ、サーバは「引けなかった」と
  答える。** 理由には欠けた辞書と「登録には進みません」を添える。TIP は
  サーバの「引けなかった」を、見出しを打っているあいだ知らせの窓に出す。
  辞書登録には進まない。これは初めての読み込みを待つあいだと同じ道である。
- 候補が見つかった語は、そのまま答える。欠けた辞書のせいで、ほかの辞書の
  語まで使えなくはしない。
- 欠けた URL の辞書は、5 分以上経ってから次に設定を尋ねられたとき
  (入力先を切り替えたとき) に取り直す。取れたら、知らせは消える。
- **更新を確かめられなかっただけなら知らせない。** 前の版で引けるので、
  記録に残すだけにする。通信できないのはよくあることで、そのたびに窓が
  出てはうるさい。

## 帰結

- 辞書が欠けているあいだは、新しい語を辞書登録できない。欠けた辞書を
  設定から外すか、取得できるようになるまで待つことになる。
- 知らせはトレイやトーストには出さない。変換しようとしたときにだけ出るので、
  困っていない人を煩わせない。
