# ADR-0035: 押すキーは枠で囲んで見せ、窓の角は DWM に丸めさせる

- ステータス: Accepted
- 日付: 2026-09-25
- 関連: ADR-0015, ADR-0019, ADR-0026

## 背景

候補の窓は、四角い枠の中に `a: 漢字` のような行を並べ、選んでいる行は地と文字の
色を入れ替えて示していた。利用者は、見た目が野暮ったいので、モダンで簡素な
ものにしたいと言った。

## 決定

- **押すキーは、角の丸い枠 (キーキャップ) で囲んで本文の左に出す。** `a:` の
  ような記号は使わない。枠はどのキーでも同じ大きさの正方形にし、本文の書き出し
  を揃える。キーは刻印に合わせて大文字で出す。
- 候補の一覧では行を選ばない (選ぶのはキーを押すことである)。動的補完の一行も
  受け取るキーを同じ枠で出す。
- Tab で補完を巡っているあいだはキーを出さず、選んでいる行に角の丸い帯を敷き、
  左端に細い印を立てる。**印の幅はどの行にも空けておき、選ぶ行が変わっても
  本文の書き出しを動かさない。**
- 枠と印の色は設定の `key` で決める。雛形では `"accent"` にした。ハイコント
  ラストのときは、ほかの色と同じくシステムの色 (`COLOR_HIGHLIGHT`) に従う。
- 窓の角は DWM に丸めさせ (`DWMWCP_ROUNDSMALL`)、影を付ける (`CS_DROPSHADOW`)。
  影が出るなら枠は引かない (`DWMWA_COLOR_NONE`)。影を切っているときと
  ハイコントラストのときは、DWM に丸みに沿って `border` の色で引かせる。
  Windows 10 のように丸められないときは、これまでどおり四角い枠を自分で描く。
- カーソルのそばのモードの窓 (ADR-0025) も同じく角を丸めて影を付け、絵の
  まわりの余白を丸みの分だけ広げる。二つの窓の DWM への頼みは `popup` にまとめた。
- **選んでいる行の `"system"` は、`COLOR_HIGHLIGHT` ではなく地と文字から作る。**
  帯の地は地に文字の色を 1 割ほど混ぜた色、文字は本文と同じ色にする。強調の色で
  塗ると帯が重く、同じアクセントの印も埋もれる。色を直に書けば、これまでどおり
  それが使われる。雛形は `"system"` のままで、既存の設定ファイルもそのまま新しい
  見た目になる。
- 雛形の明るい組の地を `"system"` から `"#F9F9F9"` に、文字を `"#000000"` に
  変えた。標準の地の色
  (`COLOR_WINDOW`) は真っ白で、Windows 11 のメニューとも違う。暗い組の地が
  地と文字を直に書いてあるのと揃え、地と文字は明暗どちらも色で書く。既存の設定ファイルの値は書き換えない
  (ADR-0020)。

## 結果

- 候補の窓は Direct2D と DirectWrite で描く (`draw`)。GDI では小さな丸みが
  なめらかにならず、半透明も扱えない。描く先はアルファを持たせてあり、あとで
  窓の地を透かせる。モードの窓の絵は画素で作るので GDI のままである。
- 候補の窓の地は DWM に透かさせる (`DWMSBT_TRANSIENTWINDOW`、Windows 11 の
  メニューと同じ Acrylic)。明暗は地の色の明るさで教える。「透明効果」を切って
  いるとき、ハイコントラストのとき、Windows がこれを知らないときは、地の色で
  塗る。透かしたままでは後ろが明るいと暗い窓の文字が読めないので、地の色を
  設定の `backdrop_opacity` (百分率、雛形では 65) の濃さで重ねる。透かした地は窓が前面でないと単色に落ちるので、`WM_NCACTIVATE` を
  いつも前面として扱わせる。
- ハイコントラストのときは、選んでいる行も含めてシステムの色 (`COLOR_HIGHLIGHT`)
  に従う。
