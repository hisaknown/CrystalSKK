# ADR-0018: 印は文書に出さない

- ステータス: Accepted
- 日付: 2026-09-23
- 関連: ADR-0017, PRD Q-09

## 背景

SKK は未確定の状態を `▽` `▼` `*` で示す。Emacs の SKK から続く見慣れた顔で
あり、状態が一目で分かる。

一方で、**記号は文書に混ざる**。書いている文の中に `▽` が挟まると、そこだけ
文字の並びが乱れる。`▽おく*り` は四文字のかなに二つの記号が割り込んでいる。

ADR-0017 で下線が部分ごとに変わるようになった。**状態を示すものが二つに
なった**ことになる。

## 決定

**文書に出す印は空白にする。** 記号そのものは出さない。

```
▽おく*り   →   ␣おく␣り
```

状態は下線で分かる。見出し語は点線、送り仮名は破線、候補は太い実線
(ADR-0017)。記号まで並べると、同じことを二度言うことになる。

## 消さずに空白を残す

詰めてしまうと区切りが見えなくなる。`おくり` では、どこからが送り仮名か
分からない。空白なら**空きで区切りが分かる**。

下線が引かれる場所が一文字ぶん増えるのも、都合がよい。空白にも線が引かれる
ので、**未確定の範囲がどこからどこまでかが見える。**

## CLI は記号のまま

ターミナルに下線は引けない。**そこでは記号が唯一の手がかり**になる。

同じ `Preedit` から違う見せ方をしているだけで、食い違ってはいない。印を
独立した区切り (`Role::Marker`) として持たせてあるので、**どう見せるかは
front end の裁量**になっている。

## 帰結

- 区切りの `*` は `Okuri` の中に埋め込まれていたが、印として独立させた。
  埋め込んだままだと、この選択ができなかった。
- **見出し語と送り仮名の線の差は、いま点線と破線でほとんど出ない。**
  ADR-0017 では「境は `*` が担っている」としていたが、その `*` が空白に
  なった。空きがあるので境は見えるものの、線だけで見分けたいなら選び直す
  余地が残る。
- 記号を好む人のために戻せる場所は、定数一つ (`MARKER_TEXT`) にしてある。
  設定で選べるようにするときの置き場所になる。
