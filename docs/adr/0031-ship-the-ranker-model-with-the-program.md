# ADR-0031: 候補を並べる言語モデルはプログラムと一緒に配り、llama.cpp は公式から取得する

- ステータス: Accepted (モデル一式の配り方は ADR-0036 で改めた)
- 日付: 2026-09-23
- 関連: ADR-0020, ADR-0030

## 背景

ADR-0030 で、変換の候補を小さな言語モデルで並べることにした。そこでは
モデル・語彙・llama.cpp の在りかを設定に書かせていたが、配り方は決めて
いなかった。

- 使うモデルは llm-jp-3-150m と決めた。利用者が別のモデルに替える理由は
  ほとんど無く、替えられても並べ方の調整 (辞書の順の重みなど) が合わない。
- llm-jp-3 のベースモデルには、既存の GGUF 版が無い。こちらで変換する
  必要がある。変換には Python・torch・llama.cpp のソースが要り、llama.cpp
  の変換スクリプトは llm-jp の語彙の前処理を知らずに止まる。
- 変換した GGUF の語彙 (結合規則の無い BPE) は、そのままでは llama.cpp が
  読めない。トークン化は CrystalSKK が tokenizer.json で行うので、GGUF の
  語彙は読み込みを通すためだけにある。
- 使用許諾: llm-jp-3 は Apache License 2.0、llama.cpp と ggml は MIT、
  llama.cpp の配布物に入っている libomp は Apache License 2.0 with LLVM
  exception。llama.cpp の公式の配布物には、llama.cpp 自身の使用許諾の本文が
  入っていない。
- いまの配り方はソースからの導入だけで、インストーラーはまだ無い。

## 決定

- **言語モデルはプログラムの一部とし、選ばせない。** 設定からモデル・語彙・
  llama.cpp の在りかを外す。ADR-0030 の「設定に `[ranker]` を足す」の
  うち、この三つを改める。残るのは有効か、辞書の順の重み、締め切り、
  前後の文章の文字数、スレッド数。
- **置き場所は辞書サーバの隣の `ranker` に固定する**
  (`%ProgramFiles%\CrystalSKK\ranker`)。辞書と違い利用者のデータでは
  ないので、`%LOCALAPPDATA%` には置かない。
- **モデル一式は `tools/ranker-model/build.py` で作る。** 元のモデルと
  llama.cpp の版を固定し、GGUF にして Q4_0 に量子化し、語彙の形式を
  書き直し、使用許諾の本文と手を加えた点 (NOTICE.md) を添える。
  llama.cpp のファイルは書き換えず、変換の前処理の判定だけをスクリプトの
  中で差し替える。**作り直しても同じバイト列になる。**
- **モデル一式はプログラムと一緒に配る。** いまは `install` がビルド成果物と
  同じく手元 (`target/ranker-model/out`) から写す。インストーラーを作る
  ときは、この一式を同梱する。`install` はハッシュをコードに持ち、
  知らないものは置かない。
- **llama.cpp は公式のリリースから取得する。** 版を固定した CPU 版の zip を
  取り、ハッシュを確かめ、要る DLL だけを取り出す。こちらから再配布
  しないので、llama.cpp の使用許諾の本文を添える立場にない。
- **揃わなくても導入は止めない。** 並べ替えが効かないだけで、変換は辞書の
  順でできる。

モデルを別の場所で公開し、導入のときに取得する案も考えた。公開する場所・
版の付け方・その場所を保ち続ける責任が増えるわりに、プログラムと一緒に
配れば済むことなので採らなかった。

llama.cpp の DLL もモデルと一緒に配る案も考えた。取得先は一つで済むが、
他人のバイナリを再配布することになる。公式から直接取るほうが穏当である。

## 帰結

- 設定で選べるものが減る。モデルを替えたくなったら、プログラムを替える
  ことになる。
- インストーラーには約 86 MB のモデルが入る。
- 導入には、初回と llama.cpp の版を上げたときに通信が要る (約 18 MB)。
  通信できなければ、並べ替えが効かないまま導入が終わる。
- llama.cpp の版を上げるときは、`crystalskk-lm` の FFI、`build.py` の版、
  `install` の zip の名前とハッシュ、モデルのハッシュをまとめて替える。
- llama.cpp の公式リリースから古い版の配布物が消えたら、版を上げるしかない。
