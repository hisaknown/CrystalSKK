# ADR-0036: 候補を並べる言語モデルは GitHub Release に置き、導入のときに取得する

- ステータス: Accepted
- 日付: 2026-09-25
- 関連: ADR-0030, ADR-0031

## 背景

ADR-0031 で、言語モデル一式 (`model.gguf` ほか) はプログラムと一緒に配ると
決めた。インストーラーがまだ無いので、いまは `install` が手元の
`target/ranker-model/out` から写している。

- 一式を得るには `tools/ranker-model/build.py` を動かすしかない。uv・Python・
  torch と、元のモデルの取得 (数百 MB) が要り、ソースから導入するたびに
  利用者がそれを負うのは重すぎる。
- 一式は約 94 MB で、うち `model.gguf` が約 84 MB ある。
- リポジトリは GitHub で公開した (`hisaknown/CrystalSKK`)。Release の
  アセットには 2 GB までのファイルを置ける。
- `build.py` は作り直しても同じバイト列を出し、`install` はそのハッシュを
  コードに持っている。
- llama.cpp の DLL は、すでに GitHub Release から取得し、ハッシュを
  確かめてから置いている。
- llm-jp-3 は Apache License 2.0 で、使用許諾の本文と NOTICE を添えれば
  再配布できる。一式にはどちらも入っている。

## 選択肢

### A. 一式を Git に入れる

- 利点: クローンすれば揃う。取得先を別に持たなくてよい。
- 欠点: 84 MB が履歴に残り続け、作り直すたびに積み上がる。ソースを読む
  だけの人や CI にも重いクローンを強いる。GitHub は 50 MB を超える
  ファイルに警告を出し、100 MB で push を拒む。

### B. Git LFS に置く

- 利点: 履歴は軽いまま、クローンで揃う。
- 欠点: 無料で使える容量と転送量に上限があり、クローンや CI のたびに
  転送量を使う。上限に届くと取得できなくなる。

### C. GitHub Release のアセットに置き、導入のときに取得する

- 利点: リポジトリは軽いまま。llama.cpp と同じ仕組みで取れる。ハッシュを
  コードに持つので、誰が作った一式でも同じものしか置かれない。
- 欠点: 導入に通信が要る。Release を消すと古い版が導入できなくなる。

### D. いまのまま (手元で作らせる)

- 利点: 何も足さなくてよい。
- 欠点: 背景に書いた重さを、ソースから導入する人が負い続ける。

## 決定

**C を採る。** 一式を `ranker-model-1` のようなタグの Release に、ファイル
ごとのアセットとして置く。`install` は、手元に一式 (`--ranker-from` か
`target/ranker-model/out`) があればそれを写し、無ければ Release から取得
する。どちらの場合もハッシュを確かめ、一つでも合わなければ何も置かない。

- タグは本体の版と切り離す。モデルは本体ほど頻繁には変わらない。
  一式を作り直したら、新しいタグを切り、コードのタグとハッシュを
  まとめて替える。古いタグは消さない。
- 手元の一式を先に使うのは、`build.py` を変えて試すときに、公開する前の
  一式を置けるようにするため。

ADR-0031 は「モデルを別の場所で公開し、導入のときに取得する案」を、公開
する場所を保ち続ける責任が増えるとして退けた。リポジトリを GitHub で
公開したいま、その Release に置けば、保つべき場所はリポジトリそのもので
あり、新しく増えるものは無い。A と B は、履歴か転送量のどちらかを
モデルの大きさに縛らせるので採らなかった。

インストーラーを作るときは、リリースの workflow が同じアセットを取って
同梱する。ADR-0031 の「インストーラーには一式を同梱する」は変えない。

## 帰結

- ソースから導入する人は、`build.py` を動かさずに並べ替えを使える。
- 導入の初回と、モデルを替えたときに約 94 MB の通信が要る。通信できな
  ければ、ADR-0031 と同じく並べ替えが効かないまま導入が終わる。
- モデルを替えるときは、`build.py` で作り、新しいタグの Release に上げ、
  `crystalskk-setup` のタグとハッシュを替える。
- Release のアセットを消したり差し替えたりすると、そのタグを指す版が
  導入できなくなる。アセットは一度上げたら替えない。
