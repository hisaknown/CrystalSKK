# ADR-0024: アイコンは SVG を正本にしてビルドのときに描き、モードの絵はタスクバーの明るさに合わせる

- ステータス: Accepted
- 日付: 2026-09-23
- 関連: ADR-0009, PRD N-08

## 背景

アイコンは二種類ある。

- **入力モードの絵** — トレイ (言語バーの入力モード項目) に出る。モードごとに
  一枚。言語バーの項目が `GetIcon` で `HICON` を返す。
- **顔の絵** — 設定画面や入力方式の一覧に出る。導入のときに `.ico` を書き
  出し、`RegisterProfile` に渡す (ADR-0009)。

どちらも仮の絵を GDI で描いていた。利用者が Inkscape で SVG を描いたので、
それを正本にする。

**IME がテーマ別の絵を渡す口は無い。** 言語バーの項目は `HICON` を一枚
返すだけで、一覧の絵は導入のときに一度登録するだけである。

## 決定

### 絵の正本は SVG

`assets/icons/` に置く。

| ファイル | 中身 |
|---|---|
| `mode-hiragana.svg` | あ |
| `mode-katakana.svg` | ア |
| `mode-halfwidth-katakana.svg` | ｶﾅ |
| `mode-ascii.svg` | A |
| `mode-fullwidth-ascii.svg` | Ａ |
| `mode-off.svg` | 切 (－) |
| `face.svg` | 顔 (色付き) |

TIP の `build.rs` が、ビルドのたびに各大きさに描いて DLL に埋め込む。
**描いたものはリポジトリに置かない。** 絵を直すときは SVG を差し替えるだけで
よい。

描くのは `resvg`。純 Rust で、C のツールチェインを求めない (N-08)。**文字を
描く機能は外す**。文字のままの SVG は、描いた結果がビルドする機械の字体に
左右されるので、アウトライン化してもらう。`<text>` が残っていればビルドを
止める。

### 入力モードの絵は単色で、タスクバーの明るさに合わせる

- SVG から**濃さ (透過度) だけ**を取り出して埋め込む。SVG の色は使わない。
  描き手は黒一色で描けばよく、薄くしたいところは不透明度で表す。
- 動くときに色を付ける。**タスクバー**が明るければ黒、暗ければ白。Windows
  標準の IME と同じ見え方になる。見るのはアプリの明るさ
  (`AppsUseLightTheme`) ではなく、タスクバーの明るさ
  (`SystemUsesLightTheme`)。絵が載るのはタスクバーで、二つは別々に選べる。
- 明暗が変わったら言語バーに描き直させる。変化は `WM_SETTINGCHANGE`
  (`"ImmersiveColorSet"`) で聞く。全体に配られる知らせは知らせ専用の窓には
  届かないので、見えないふつうの窓を一枚持つ。念のため、入力先が変わる
  たびにも確かめ直す。
- 大きさは 16〜64 画素を、よく使われる拡大率の分だけ描いておく (16, 20, 24,
  28, 32, 36, 40, 48, 64)。近い大きさを縮めて使うと滲む。
- 色を濃さと分けて持つので、**色を設定で選べるようにするのは容易**である
  (`Theme::ink` を差し替える)。

### 顔の絵は色付きで、テーマに追従しない

一覧の絵は差し替える口が無い。どちらのテーマでも読める絵にしてもらい、
色付きの `.ico` (16〜256 画素) にする。256 画素は PNG で、それより小さい
ものは 32 ビットの BMP で入れる。半透明も効くが、後ろの色が透けるので、
二つのテーマで違って見える。

## 帰結

- 絵の差し替えは SVG の差し替えだけで済む。DLL を作り直せば入る。
- ビルドのときだけ `resvg` が要る。DLL には描いた結果しか入らないので、
  大きさはほとんど変わらない。
- 見本は `cargo run -p crystalskk-art --example sheet -- <出力.png> <SVG>...`
  で作れる。明るい地と暗い地に、実際の色で並べる。
- 見直す条件: Windows が IME にテーマ別の絵を渡す口を用意したとき。
