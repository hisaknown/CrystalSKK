# ADR-0022: 設定に並べた辞書を、一つの辞書であるかのように引く

- ステータス: Accepted
- 日付: 2026-09-23
- 関連: ADR-0004, ADR-0016, ADR-0020, PRD F-10, PRD §5.2

## 背景

静的辞書は L 辞書に固定だった。取得元の URL は `crystalskk-fetch` の定数、
置き場所は `%LOCALAPPDATA%\CrystalSKK\SKK-JISYO.L` 一つで、取得は利用者が
`crystalskk-setup dict` を打ったときだけだった。

利用者の要件は次のとおり。

- 使う辞書を設定で指定できる。
- URL を書けば、自動で取得する。
- 複数の辞書を、**結合してあるかのように**使う。ファイルとして結合して
  ある必要はない。

## 決定

### 書き方

`config.toml` に辞書の並びを置く (ADR-0020 の約束どおり、効いている並びは
ファイルに書かれている)。

```toml
[dictionaries]
sources = [
    "https://raw.githubusercontent.com/skk-dev/dict/master/SKK-JISYO.L",
]
```

- `http://` か `https://` で始まれば URL。取得して手元に置く。
- それ以外はファイルの場所。直に読む。相対なら設定ファイルと同じ場所から。
- 空の並びも許す (ユーザー辞書だけで使う)。

並びは `config.toml` の一項目なので、消せば雛形 (L 辞書一つ) で書き戻される。
並べた中身を書き換えることはしない。

### 結合したかのように引く

ファイルとしては結合しない。辞書ごとに更新の頻度も使用許諾も違うので、
別々に持つほうが扱いやすい。代わりに、引き方を揃える。

- **ユーザー辞書を先に**、そのあと並べた順に引く。同じ語は先に出たほうに
  まとめる。一つのファイルに順に結合し、同じ見出しの候補を併合したときと
  同じ並びになる。
- 補完は全部の辞書から集め、**見出しの辞書順**に並べ直す。一つのファイル
  だったら、そう並んでいる。ユーザー辞書の使った順が先に来るのは変わらない
  (ADR-0019)。

### 取得の置き場所

`%LOCALAPPDATA%\CrystalSKK\dictionaries\<ホスト>\<パス>` に置く。L 辞書なら
`dictionaries\raw.githubusercontent.com\skk-dev\dict\master\SKK-JISYO.L`。

**置き場所を見れば取得元が分かる**ようにしたい。名前だけ (`SKK-JISYO.L`) だと、
別の場所から取った同じ名前の辞書とぶつかる。ファイル名に使えない文字や `..` は
`_` に換え、置き場所の外へ出ないようにする。前回の `ETag` を隣の `.etag` に
覚える。

### いつ取得するか

- **手元に無ければ、辞書サーバが裏で取る。** 導入した直後や、並びに新しい
  URL を足したときがそれにあたる。
- **更新は、辞書サーバが起動したときに一度だけ確かめる。** `ETag` を添えて
  尋ね、変わっていなければ中身を落としてこない。入力先を切り替えるたびには
  通信しない。
- `crystalskk-setup dict` は、いま取り直したいときと、何が起きたかを見たい
  ときに使う。辞書サーバには知らせる相手がいない。
- 取得できなかったとき、手元に前のものがあればそれで続ける。無ければその
  辞書は抜けたまま、ほかの辞書とユーザー辞書で答える。次の起動でまた試す。

### 取得中は「引けなかった」と答える

L 辞書の取得には数秒かかる。そのあいだに「無い」と答えると、**知っている
はずの語で辞書登録が始まる**。

- 取得と読み込みは裏のスレッドで行い、できたら差し替える。頼みは待たせない。
- 一度も読み終えていないあいだ、検索には「辞書を取得しています」と答える。
  TIP はこれを「辞書に繋がりません」と同じく**引けなかった**として扱い、
  言われた文を候補の窓に出す。辞書登録は始まらない。
- 二度目からは、読み直しているあいだも前の辞書で答える。

### 読み直し

並びが変わるか、並べたファイルの時刻が変わっていれば、裏で読み直す。
確かめるのは設定を尋ねられたとき (入力先を切り替えたとき) である。
`crystalskk-setup dict` で取り直した辞書も、これで読み込まれる。

### かつての置き場所

`%LOCALAPPDATA%\CrystalSKK\SKK-JISYO.L` はもう読まない。CrystalSKK が
取ってきたものなので、導入と `dict` のときに片付ける。

## 帰結

- 別の辞書 (jinmei、geo、自作の辞書など) を足すには、並びに一行書くだけで
  よい。
- 並べた順が候補の順になる。L 辞書より先に出したい辞書は、上に書く。
- 取得に失敗した辞書は、辞書サーバの出力にしか現れない。サーバには知らせる
  相手がいないため。`crystalskk-setup dict` を打てば見える。窓で知らせる
  道は、必要になったら足す。
- 取得の試験はネットワークに出ない。取得の処理を差し替えられるようにして
  ある (`Library::new` の `fetch`)。
