# ADR-0014: 隔離されたアプリには辞書を読ませる。書かせはしない

- ステータス: Superseded by 0016
- 日付: 2026-09-23
- 関連: ADR-0011, PRD §7

## 背景

ストアアプリやスタートメニューの検索欄では、変換が一件も引けなかった。
記録には `ユーザー辞書を読んだ: 0 件` とだけ出ていた。

これらは AppContainer という隔離された入れ物の中で動く。そこでは二つのことが
同時に崩れる。

1. **場所が違う。** `%LOCALAPPDATA%` は入れ物ごとの場所へ読み替えられる。
   辞書はそこには無い
2. **読む権利が無い。** 場所が分かっても、利用者の領域は既定では読めない

CorvusSKK の作者も同じことを書いている。

> AppContainerの外とファイル読み書きやプロセス間通信をおこなう必要がある
> IMEは、予め設定ファイルなどのオブジェクトに対してAppContainer内から
> 読んでもいいよ、という状態に設定しておきます

## 決定

**両方に手当てする。片方だけでは直らない。**

- 置き場所は環境変数ではなく Win32 に尋ね、**入れ物への読み替えをしない**
  よう明示する (`KF_FLAG_NO_APPCONTAINER_REDIRECTION`)
- 辞書の置き場所に、隔離された入れ物からの**読み**を許す。受け継がれる形で
  与えるので、あとから置いた辞書にも付く

許す相手は二つある。`AC`（すべてのアプリケーションパッケージ）と、SID を直に
書いた `S-1-15-2-2`（制限されたすべてのアプリケーションパッケージ）である。
**SDDL の略号 `RC` は後者ではない。** 「制限されたコード」という別のものに
解決される。CorvusSKK は `RC` を使っているが、`%ProgramFiles%` の既定に
入っているのは `S-1-15-2-2` のほうで、より絞られた入れ物 (LPAC) で動くものは
そちらに当たる。

## 置き場所ごと開けてはいけない

最初は置き場所に読みを与え、中のファイルへ受け継がせた。**同じ場所に診断の
記録があることを見落としていた。** 記録は `trace` にすると打鍵を残す。機械中の
隔離されたアプリが、それを読める状態になっていた。

そこで与え方を細くした。

- **フォルダには「たどる」だけ** (`FX`)。読み (`FR`) は与えない。読めると
  中に何があるか並べて見られる
- **辞書のファイルにだけ「読む」**。名前を知っているものしか開けない
- 受け継がせない。挙げていないファイルには何も付かない

許可は**辞書を置いたあとに**与える。先に与えても、置き換えられたファイルは
新しく作られるので引き継がれない。

## 書き込みは許さない

**許せば、隔離された入れ物で動くあらゆるアプリが利用者の辞書を書き換えられる。**
隔離されている意味が薄れる。

代償として、そうした場所では学習が残らない。変換はできるが、選んだ候補の
順番は覚えられない。

これは妥協であって答えではない。**本来の答えは、辞書を別プロセスに持たせる
こと** (PRD §7) である。入れ物の中の TIP は書き込む必要がなく、外のプロセス
へ頼めばよい。CorvusSKK が `imcrvmgr` を分けているのもこのためで、あちらも
入れ物の中からは書かせていない。

## 取り下げた

**ADR-0016 で辞書サーバができ、この許可は要らなくなった。** 辞書を読むのは
サーバだけで、サーバは隔離された入れ物の外にいる。TIP はファイルに触れない。

要らない許可は外す。与えた相手は「あらゆる隔離されたアプリ」という集団で、
その中に利用者の辞書を覗く理由のあるものはいない。とくに `user.dict` には
**利用者が登録し、学習した語**が入る。

導入のたびに取り下げるので、すでに与えてしまった機械でも外れる。

本 ADR は、**書き込みを許さなかった判断が正しかったこと**の記録として残す。
あのとき書き込みまで許していたら、いま外すだけでは済まなかった。

## 帰結

- 置き場所を解くのに Win32 を呼ぶので、`paths` は `crystalskk-tip` へ移した。
  **`unsafe` は TIP クレートだけに置くという境界**を崩したくなかったため。
- 許可は `dict` と `install` の両方で与え直す。辞書を先に置いていた人を
  置き去りにしない。
- 与えられなくても普通のアプリでは使えるので、失敗しても導入は続ける。
- **「読ませたいもの」と「同じ場所にあるもの」は違う。** 置き場所ごと開けると、
  後から置いたものまで一緒に開く。開ける単位は、許す相手ではなく**許す対象**で
  絞る。
