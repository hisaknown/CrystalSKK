# ADR-0013: 入が常態で、切は SKK に手を引かせるためにある

- ステータス: Accepted
- 日付: 2026-09-23
- 関連: ADR-0012

## 背景

ADR-0012 で入切を区画から読むようにした。読むと決めた以上、**入にされた
直後にどのモードから始めるか**を決めなければならない。

日本語入力の慣例では「入にする＝日本語を打ち始める」なので、かなから
始めるのが自然に見える。CorvusSKK の既定もそちらである。

## 決定

**半角英数から始める** ([`DEFAULT_MODE`])。

SKK の使われ方が、他の日本語入力と違うためである。

- **入は常態である。** SKK では入れっぱなしで英字も日本語も打つ。英字は
  半角英数モード (`l`) で打てばよく、入力方式を切る理由がない
- **切は「CrystalSKK に手を引かせる」ための状態である。** `Ctrl+J` や
  `q` を横取りされたくないとき — 他の道具がその打鍵を使うとき — にだけ切る

この使われ方では、切から入へ移る場面は「日本語を打ちたくなった」瞬間とは
限らない。**入にしただけで打鍵の意味が変わると、英字を打つつもりだった人が
かなを掴まされる。** かなへは `Ctrl+J` で自分から入る。SKK ではそれが普通の
入り方なので、一手増えたことにはならない。

## 帰結

- **入で半角英数の状態と、切の状態は、打った見た目が同じになる。** 違うのは
  トレイの表示 (`A` か `－` か) と、`Ctrl+J` が効くかどうかだけである。
  紛らわしければ、切の表示をさらに違う顔にする余地がある。
- **入力方式として選ばれた時点で、切られていたら入にする。** 常態だと
  言いながら切のまま始まると、利用者は新しいアプリを開くたびに入切の
  キーを押すことになる。入って半角英数なら打鍵の意味は切と変わらないので、
  勝手に入れても邪魔にならない。
  ただしこれを行うのは**有効化のとき一度だけ**である。焦点が移るたびに
  やれば、利用者が意図して切ったものを勝手に入れ直すことになる。
- 既定値は定数一つに集めてある。**設定で選べるようにするときの置き場所は
  ここ**で、「入にしたらかな」を好む人のための切り替えはそこへ足す。
- 切のときに打鍵を食べないことは ADR-0012 で決めた。本 ADR はその上で、
  **切を「入力方式が使えない状態」ではなく「利用者が意図して黙らせた状態」**
  として扱うことを言っている。だから切ったことは表示にはっきり出す。
